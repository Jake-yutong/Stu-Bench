# Stu-Bench Demo

Local-first research workbench for evaluating LLM-simulated students in scaffolded tutoring interactions.

## Development

Backend:

```bash
pip install -e ".[dev]"
npm run backend:dev
```

Tests:

```bash
npm run backend:test
```
